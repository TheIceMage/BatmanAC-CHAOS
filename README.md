The Arkham City CHAOS Mod is inspired by the GTA CHAOS Mod: Random effects trigger every 30 seconds. Made with [BmSDK](https://bmsdk.dev).

## INSTALLATION INSTRUCTIONS

1. Install [BmSDK](https://github.com/Team-BmSDK/BmSDK-AC#-getting-started)
2. Download the [latest release](https://github.com/TheIceMage/BatmanAC-CHAOS/releases/latest) of the mod
3. Extract the ZIP into your game folder merging the existing Binaries and BmGame folders with the provided ones
4. You should be able to run the mod by starting the game now

## CONTROLS

F11 - ENABLE/DISABLE Effects HUD
F12 - START/STOP Timer
