The Arkham City CHAOS Mod is inspired by the GTA CHAOS Mod. Random effects trigger every 30 seconds.

## REQUIREMENTS

1. Install the [BmSDK](https://github.com/etkramer/BmSDK).

## CONTROLS

F11 - ENABLE/DISABLE Effects HUD
F12 - START/STOP Timer
